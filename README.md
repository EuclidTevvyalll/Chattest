# Rick and Morty App

Премиальное мобильное приложение на Flutter для просмотра персонажей вселенной "Рик и Морти". Проект демонстрирует современные подходы к разработке, включая чистую архитектуру, реактивное управление состоянием и продвинутый UI.

## Описание проекта

Приложение предоставляет пользователю возможность исследовать каталог персонажей мультсериала, просматривать детальную информацию о каждом из них, добавлять в избранное и просматривать в офлайн-режиме.

### Основные функции:
- **Бесконечный список**: Пагинация персонажей с плавной подгрузкой.
- **Детальная информация**: Интерактивные модальные окна с характеристиками персонажа.
- **Избранное**: Система сохранения персонажей в локальное хранилище с мгновенной синхронизацией UI.
- **Офлайн-кэширование**: Автоматическое сохранение данных API для доступа без интернета.
- **Мультиязычность**: Полная локализация интерфейса (Русский / Английский).
- **Дизайн**: Современный Glassmorphism UI с мягкими тенями и тактильными анимациями.

## 🛠 Технологии и Архитектура

### Архитектура
Проект построен по принципам **Clean Architecture** с разделением на слои и использованием **Feature-driven** структуры:
- **Domain**: Сущности и интерфейсы репозиториев (бизнес-логика).
- **Data**: Реализация репозиториев, модели данных (DTO) и внешние источники (API/Cache).
- **Presentation**: Виджеты, экраны и провайдеры состояния (Riverpod).

### Технологический стек:
- **Riverpod**: Реактивное управление состоянием и внедрение зависимостей.
- **GoRouter**: Декларативная навигация с поддержкой `ShellRoute`.
- **Dio + Fpdart**: Сетевые запросы с функциональной обработкой ошибок (`Either`).
- **Shared Preferences**: Локальное хранилище для избранного и кэша.
- **Freezed & JSON Serializable**: Генерация неизменяемых моделей и сериализация JSON.
- **Flutter Hooks**: Оптимизация жизненного цикла виджетов.
- **Glassmorphism & Bounceable**: Кастомные визуальные эффекты и анимации.

### Запуск проекта:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/DSF1re/test.git
   ```

2. Перейдите в директорию проекта:
   ```bash
   cd rickandmorty
   ```

3. Установите зависимости:
   ```bash
   flutter pub get
   ```

4. Сгенерируйте необходимые файлы (локализация и модели):
   ```bash
   # Генерация локализации
   flutter gen-l10n
   
   # Генерация моделей (freezed/json_serializable)
   flutter pub run build_runner build --delete-conflicting-outputs
   ```

5. Запустите приложение:
   ```bash
   flutter run
   ```
